## Die Regel, die alles zusammenhaelt

**Eroeffnen verlangt ein Konto, Mitspielen nicht.** Wer eine Partie eroeffnet,
belegt Rechenzeit - dort leistet ein Konto etwas. Wer mitspielt, tippt Code
und Namen. Die zweite Schicht darunter ([Schutz](schutz.md)) greift ohne
Ansehen der Person, weil ein Angreifer gar kein Konto will.
